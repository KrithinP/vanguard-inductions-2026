# The Sols

These are the tasks. Do them in order — each builds on the last, and Sol 1 is
what everything else stands on.

**Sols 1–3 are compulsory. Sol 4 is a bonus** — it can only add to your
evaluation, never subtract, and finishing it earns serious brownie points.

## Work from these

Each PDF is the **complete task in one file**: the brief, plus every handbook
chapter it depends on, bundled inline and in order.

- **Sol 1** — [Windows](sol1-windows.pdf) · [macOS](sol1-macos.pdf) · [Linux](sol1-linux.pdf)
- **Sol 2** — [sol2-rover.pdf](sol2-rover.pdf)
- **Sol 3** — [sol3-vision.pdf](sol3-vision.pdf)
- **Sol 4** — [sol4-autonomy.pdf](sol4-autonomy.pdf) · bonus

Only Sol 1 differs by operating system. The rest are the same for everyone.

## The Markdown briefs

[sol1.md](sol1.md) · [sol2.md](sol2.md) · [sol3.md](sol3.md) · [sol4.md](sol4.md)

These are the **brief only** — what to build and what to hand in — with links out
to the [`handbook/`](../handbook/) chapters. They're here so anyone browsing the
repo can see what the induction involves without downloading anything.

**If you're doing the induction, use the PDFs.** They have everything in one
place, in the right order, and work offline.

## The help thins out as you go

Sol 1 hands you a working example. By Sol 4 you get the problem described and
build it yourself. That is deliberate.

## Checking yourself

```bash
./tools/vanguard check
```

Reports GO / NO-GO for each Sol you have started. Sols you haven't begun are
reported as not started and can never fail your build.
