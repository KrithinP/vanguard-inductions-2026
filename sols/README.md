# The Sols

These are the tasks. Do them in order — each builds on the last, and Sol 1 is
what everything else stands on.

| | | | | |
|---|---|---|
| **Sol 1** | [sol1.md](sol1.md) | [Windows](sol1-windows.pdf) · [macOS](sol1-macos.pdf) · [Linux](sol1-linux.pdf) |

| **Sol 4** | [sol4.md](sol4.md) | [PDF](sol4-autonomy.pdf) |

The Markdown and the PDF are the same thing; the PDF is for reading offline.
Only Sol 1 differs by operating system.

**Sol 4 is a bonus.** It can only add to your evaluation, never subtract, and it
is deliberately harder than the others.

**You are not expected to finish all four.** Sol 1 alone, done properly and
understood, is a good submission — and counts for more than four rushed ones you
can't explain. Start at Sol 1 and get as far as you get.

The help thins out as you go. Sol 1 hands you a working example. By Sol 4 you get
the problem described and build it yourself. That is deliberate.

## Checking yourself

```bash
./tools/vanguard check
```

Reports GO / NO-GO for each Sol you have started. Sols you haven't begun are
reported as not started and can never fail your build.
