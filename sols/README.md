# The Sols

These are the tasks. Do them in order — each builds on the last, and Sol 1 is
what everything else stands on.

**Sols 1–3 are compulsory. Sol 4 is a bonus** — it can only add to your
evaluation, never subtract, and finishing it earns serious brownie points.

## Checking yourself

```bash
./tools/vanguard check
```

Reports GO / NO-GO for each Sol you have started. Sols you haven't begun are
reported as not started and can never fail your build.
