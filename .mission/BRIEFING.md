# ⚠ RECOVERED DATA — MISSION DIRECTORY

The rover's flight computer took a hit during descent. Three fragments of the
mission authentication phrase survived, scattered across this directory.

Find all three. Assemble them. Authenticate.

```
FRAGMENT_1=????   somewhere in the telemetry logs
FRAGMENT_2=????   the self-test script won't run as shipped
FRAGMENT_3=????   sealed in the archive
```

You will not find these by clicking around in a file manager. Use the terminal.
Everything you need is taught in `handbook/01-terminal.md`.

When you have all three, go back to `sols/sol1/README.md` — step 8 tells you how
to authenticate.

> Why is this directory hidden? Because its name starts with a dot. Plain `ls`
> skips those. That is your first lesson.
