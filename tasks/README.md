what everything else stands on.

printing.

**Task 4 is a bonus.** It can only add to your evaluation, never subtract, and it
is deliberately much harder than the others — you write most of the code yourself.

**You are not expected to finish all four.** Task 1 done properly and understood
beats four rushed. Only Task 1's sheet differs by operating system; the rest are
the same for everyone.
